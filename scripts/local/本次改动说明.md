# AnyPrecision MOPD 本次改动说明

更新日期：2026-11-08。

## 训练与精度路由

- 支持按学生精度分组的批量生成、学生打分和训练，恢复原始样本顺序。
- 双卡可启用按精度分工的 rollout：一个 rank 生成 W4，另一个 rank 生成 W8；训练仍使用共享 FSDP 和同一个优化目标。
- 教师按学生精度匹配，避免对每条轨迹重复计算所有精度的教师。
- 支持可配置的精度损失权重，当前实验使用 W4:W8=1:2，并对权重归一化。
- 修复启用精度权重而没有 domain 信息时遍历 None 导致的训练崩溃。
- 保留批量、显存探测、日志、检查点与恢复所需的本地启动脚本。

## 校准与评估工具

- 增加 WikiText 数据准备、量化教师加载和独立 PPL 评估脚本。
- AutoRound 教师脚本支持 W2/W4/W8、group32/64/128，以及显式 SignRound/SignRoundV2 配置。
- 增加配置检查入口；实际校准使用 WikiText-2 训练集窗口，保存采样与实验配置。
- PPL 使用官方 WikiText-2 raw test，文本以两个换行拼接，无聊天模板和额外特殊 token；1024-token 非重叠分块，包含尾块，跳过每块首 token，累加 FP32 交叉熵。
- 完整测试共 291 块、296902 个计分 token；BF16 执行结果如下。

| 模型 | PPL，越低越好 |
| --- | ---: |
| 原始 Qwen3.5-0.8B BF16 | 19.389505 |
| Intel AutoRound W4 | 20.011975 |
| 本地 AutoRound W8 | 19.401943 |
| 本地 AutoRound W2 group32，SignRoundV2 | 27.950942 |

W2 正式校准使用 512 个长度为 2048 的训练窗口、1000 次迭代、batch size 8；结果目录为 `/data/anyprecision_mopd/ppl_w2_v2_cal512_test1024_20261108_061848/`。W2/W4 使用 `auto_round:torch_zp` 后端加载。不同模型的量化范围不完全相同，此表不是隔离量化算法因素的比较。

## 已执行验证

- 精度路由回归测试：16 项，14 项通过，2 项 GPU 测试跳过。
- W2 最小校准导出及 BF16 文本前向通过，正式模型完整测试通过且 NLL 有限。
- 双卡 W4/W8 全量实验已完成；相关探测与使用方式见同目录实验文档。

## 限制与后续工作

- 当前尚未实现四卡启动及四卡按精度分组，不应把双卡验证当作四卡支持。
- 尚未制作新的共享 W2/W4 AnyPrecision 学生，也未启动 W2/W4 MOPD。
- W2 并非所有权重都为 2bit：敏感投影、视觉模块和输出头保留浮点；未参与文本校准的 MTP 辅助线性权重导出时回退为 W4。
- AutoRound 是优化式 PTQ，不是全量 QAT；PPL 结果不保证蒸馏收益或打包推理性能。
- 模型、数据、校准缓存、检查点和运行日志保留在本地 `/data`，不纳入本次代码提交。
